# Architecture Decision Records

Architecture Decision Records document important, durable decisions for
actually-fine. ADRs are intentionally short and are not implementation
specifications.

## Statuses

- Proposed: under discussion
- Accepted: decision made and in force
- Superseded: replaced by a later ADR
- Rejected: considered and not adopted
